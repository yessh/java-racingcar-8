# java-racingcar-precourse

# 구현 목록

## 입력

### 입력 (`Input.class`)

- [ ]  n 개의 자동차 이름을 (,) 기준 구분하여 입력.
- [ ]  수행 횟수 입력

## 수행

### 입력 파서 ( `InputParser.class` )

- [ ]  (,)로 분류된 각 문자열 담긴 List 반환
- [ ]  수행 횟수 반환
- [ ]  올바른 입력 검증
    - [ ]  문자열 - 각 이름 글자수 검증
    - [ ]  문자열 - 영어, 숫자, 쉼표 외의 것 입력
    - [ ]  수행 횟수 - 수가 아닌 값, 음수, 너무 큰 값 입력

### Car (`Car.class` )

- [ ]  0-9 랜덤값 이용하여 4이상 전진, 미만이면 정지

### Cars (`Cars.class`)

- [ ]  이름 가진 각 자동차 생성
- [ ]  모든 Car 객체 담은 List를 반환

### 자동차 이동(`Running.class` )

- [ ]  수행 횟수 만큼 Car 움직임 명령

## 출력

### 출력(`Output.class`)

- [ ]  턴마다 자동차 위치 출력
- [ ]  최종 수행 시, 1등(또는 공동 1등) 출력
